CSS Styling & Layouts

CSS (Cascading Style Sheets) controls how your HTML looks. Learn colors, the box model, flexbox, grid, and animations to design modern, beautiful pages.

1 CSS Basics & Selectors

CSS styles HTML using selectors. The most common are element selectors (p), class selectors (.btn), and ID selectors (#header). Link a stylesheet with the <link> tag. 

            p{
                color: #2563EB;
                font-size: 16px;
            }

            .btn{
                background: #2563EB;
            }

2 Colors, Fonts & Text

Use hex colors (#2563EB), rgb, or named colors. Set fonts with font-family, size with font-size, and control spacing with line-height and letter-spacing. 

            body{
                font-family: 'Poppins', sans-serif;
                background: #F8FAFC;
                color: #0F172A;
                line-height: 1.6;
            }
💡 Tip Use a tool like a color picker to build a consistent palette of 2-3 main colors plus neutrals for text and backgrounds.

3 The Box Model

Every element is a box made of content, padding, border, and margin. Adding box-sizing: border-box keeps widths predictable. 

            .card{
                width: 300px;
                padding: 20px;
                border: 1px solid #e2e8f0;
                margin: 10px;
                border-radius: 12px;
            }

4 Flexbox

Flexbox arranges items in a row or column. Set display:flex on a container and use justify-content, align-items, and gap to position children. 

            .nav{
                display: flex;
                justify-content: space-between;
                align-items: center;
                gap: 20px;
            }

5 CSS Grid

Grid creates two-dimensional layouts. Use grid-template-columns to define columns and gap for spacing between cells. 

            .course-grid{
                display: grid;
                grid-template-columns: repeat(3, 1fr);
                gap: 24px;
            }
Flexbox or Grid? Use flexbox for one-dimensional rows/columns (like a navbar) and grid for full page or card layouts. Both are essential.

6 Transitions & Animations

Transitions animate changes between states, while keyframe animations run continuously. Add hover effects with transition. 

            .btn{
                transition: transform .3s ease;
            }

            .btn:hover{
                transform: translateY(-4px);
            }

            @keyframes float{
                50%{ transform: translateY(-15px); }
            }

7 Custom Properties

Custom properties (CSS variables) store reusable values. Define them on :root and reuse them anywhere with var(). Changing one value updates the whole site. 

            :root{
                --primary: #2563EB;
                --dark: #0F172A;
                --radius: 12px;
            }

            .btn{
                background: var(--primary);
                border-radius: var(--radius);
            }

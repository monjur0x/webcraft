1 What is HTML?

HTML is a markup language used to structure content on the web. It uses tags wrapped in angle brackets like <p> to tell the browser what each piece of content is. HTML is not a programming language — it doesn't run logic. It just describes structure. 

<p>Hello, world!</p>
💡 Tip "HTML" stands for HyperText Markup Language. "HyperText" means clickable text (links), and "Markup" means using tags to label content.

2 Page Structure

Every HTML page begins with a <!DOCTYPE html> declaration followed by the <html> root element. Inside it live two children: <head> for metadata (title, styles) and <body> for everything the user sees. 

<!DOCTYPE html>
<html lang="en">
    <head>
        <title>My Page</title>
    </head>
    <body>
        <p>Visible content here</p>
    </body>
</html>

3 Text & Headings

Headings range from <h1> (most important) down to <h6>. Use only one <h1> per page for good accessibility and SEO. Use <p> for paragraphs and <strong> or <em> for emphasis. 

<h1>Welcome to WebCraft</h1>
<h2>Getting Started</h2>
<p>This is a <strong>bold</strong>
   and <em>italic</em> sentence.</p>

4 Links & Images

Links use the <a> tag with an href attribute. Images use the self-closing <img> tag with src and alt.

Example

<a href="https://webcraft.example">Visit WebCraft</a>

<img src="logo.png" alt="WebCraft logo" width="120">
Remember Always add a descriptive alt to images — it helps screen readers and shows text if the image fails to load.

5 Lists & Tables

Use <ul> for unordered (bullet) lists and <ol> for ordered (numbered) lists. Each item goes in an <li>. Tables use <table>, <tr> (row), <th> (header cell), and <td> (data cell). 

            <ul>
                <li>HTML</li>
                <li>CSS</li>
            </ul>

            <table>
                <tr><th>Topic</th><th>Level</th></tr>
                <tr><td>HTML</td><td>Easy</td></tr>
            </table>

6 Forms

Forms collect input from users. The <form> wraps fields. Common inputs are text fields, email, passwords, checkboxes, and submit buttons. Always give a label to each field. 

            <form>
                <label>Name:</label>
                <input type="text" name="name">

                <label>Password:</label>
                <input type="password" name="pass">

                <button type="submit">Submit</button>
            </form>

7 Semantic HTML

Semantic tags describe their meaning. Using <header>, <nav>, <main>, <section>, <article>, <aside>, and <footer> makes your code readable and helps search engines and screen readers understand the page's structure. 

    <header>Site title</header>
    <nav>Navigation links</nav>
    <main>
        <article>A standalone piece of content</article>
    </main>
    <footer>Copyright info</footer>

1 Intro & Your First Script

JavaScript runs in the browser and lets you change a page after it loads. Add it with a <script> tag or an external file. Any error message you print shows up in the Console tab of your browser's DevTools. 

console.log("Hello, World!");

To open DevTools, press F12 or Ctrl+Shift+I.

2 Variables & Data Types

Variables store values. Use let for values that change and const for values that stay the same. Common data types are strings (text), numbers, booleans (true/false), and null. 

            const name = "Monju";
            let age = 25;
            const isStudent = true;

            console.log(name, age, isStudent);

3 Operators & Strings

Operators perform math (+ - * / %) and comparisons (===, !==, >, <). Combine strings with the + operator or template literals using backticks and ${}. 

            const price = 10;
            const total = price * 2; // 20

            const message = `Total cost: ${total} USD`;

4 Functions

Functions are reusable blocks of code. Define them with the function keyword, give them inputs (parameters), and return a result. 

            function greet(name){
                return `Hello, ${name}!`;
            }

            console.log(greet("Sam"));

5 Conditions & Loops

Use if/else to make decisions and for, while, or forEach to repeat code. 

            const score = 85;

            if (score >= 80){
                console.log("Excellent!");
            } else {
                console.log("Keep practicing.");
            }

            for (let i = 0; i < 3; i++){
                console.log(i); // 0, 1, 2
            }

6 Arrays & Objects

Arrays store ordered lists, accessed by index (starting at 0). Objects store named key/value pairs. Both are everywhere in real JavaScript. 

            const languages = ["HTML", "CSS", "JS"];
            console.log(languages[0]); // HTML

            const student = { name: "Ada", age: 20 };
            console.log(student.name); // Ada

7 The DOM

The DOM (Document Object Model) represents your HTML as objects. Use document.querySelector to select elements and change their text, styles, or content. 

            const title = document.querySelector("h1");
            title.textContent = "Welcome!";
            title.style.color = "blue";

8 Events

Events let your page react to user actions like clicks and typing. Attach a listener with addEventListener and run code when it fires. 

            const btn = document.querySelector("#button");

            btn.addEventListener("click", () => {
                alert("You clicked me!");
            });
💡 Tip Arrow functions like () => { } are a shorter way to write simple functions and are very common in modern JavaScript.

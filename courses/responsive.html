One Site, Every Device

1 Mobile-First Principles

Mobile-first means designing for the smallest screen first, then adding layout as the screen grows. It keeps your CSS simpler and often performs better on phones.

Why start small? Starting with a single-column layout that stacks content is very simple, then you only add horizontal layout for larger screens.

2 Viewport & Meta Tag

The viewport meta tag tells mobile browsers to size the page to the device width. Almost every responsive page includes it. 

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

3 Fluid Layouts & Units

Use percentage widths and relative units like em, rem, and vw/vh instead of fixed pixel widths so elements scale with the screen. 

            .container{
                width: 90%;
                max-width: 1200px;
                margin: auto;
            }
💡 Tip Use rem for font sizes so text scales with user settings, and avoid oversized fixed layouts.

4 Media Queries

Media queries apply styles only when a condition is true, like a minimum screen width. This lets you change columns, hide menus, or resize text at specific sizes. 

            .grid{
                display: grid;
                grid-template-columns: 1fr;
            }

            @media (min-width: 768px){
                .grid{
                    grid-template-columns: repeat(3, 1fr);
                }
            }

5 Flexible Media

Images, videos, and other media should never overflow their container. Set them to max-width: 100% and use height: auto so they keep their aspect ratio. 

            img, video{
                max-width: 100%;
                height: auto;
            }

6 Common Breakpoints

Breakpoints are the widths where your layout changes. These are common values to start from — adjust them for your actual content. 

            /* Small phones */       0 - 480px
            /* Tablets */      @media (min-width: 768px)
            /* Desktop */      @media (min-width: 992px)
            /* Wide screens */ @media (min-width: 1200px)

📖 About WebCraft

An Interactive Web Programming Learning Platform

WebCraft is a text-based learning platform for CSE0613302 — Web Programming Lab, Uttara University. Built entirely with HTML, CSS & JavaScript and deployed on GitHub Pages.

Introduction

WebCraft teaches the fundamentals of web programming — HTML, CSS and JavaScript — through structured, beginner-friendly text lessons. No paywalls, no video fatigue: just clean, self-paced content from first tag to responsive, interactive sites.

Problem We Solve

Beginners struggle to find resources that are simple, focused and free. Existing platforms are cluttered, expensive or too advanced. WebCraft fills the gap with a clear progression — fundamentals → styling & layouts → responsiveness → interactivity — all in one lightweight static site.

Project Objectives

  • Deliver a fully responsive, text-based lesson platform
  • Provide a clear path: HTML → CSS → Responsive Design → JavaScript
  • Offer a clean, modern, beginner-friendly UI
  • Stay freely accessible via GitHub Pages with no login barrier
  • Practice 10-person Git & GitHub collaboration
  • Ship a portfolio-quality front-end project

Scope

V1 focuses on front-end only: landing page, course tracks, lesson pages with code examples, navigation and progress indicators, and a contact form. Out of scope for this phase: authentication, database, payments and the AI Learning module (future enhancement).
